# 课程表小组件-Class Schedule Widget

一个高效的小组件，提醒你一天的课程和日程



课程表小组件 v1.1.0（Windows 11 x64）

========================================



一、如何运行

\------------

1\. 请先把压缩包完整解压到一个固定文件夹（例如 D:\\Apps\\课程表小组件）。

&#x20;  不要在压缩包里直接双击运行，也不要放在系统临时目录中。

2\. 双击“课程表小组件.exe”即可启动。

&#x20;  本程序是自包含版本，无需另外安装 .NET 或 Windows App Runtime。

&#x20;  首次启动会同时打开小组件和设置窗口。



二、v1.1.0 新增

\---------------

• 外观支持“浅色 / 深色 / 跟随系统”三种模式，设置里切换后立即生效。

• 小组件的课程字体、倒计时字体和幸福倒计时进度条整体放大约 50%。

• 置顶时间改为按星期设置：周一至周日可以分别设置启停和起止时间。

• 新增“临近上课 / 下课时自动置顶”：可设置提前 1–30 分钟，在课程开始前

&#x20; 或结束前的最后几分钟内自动让小组件保持最前。

• 任务栏小图标的右键菜单改为圆角、跟随主题的现代 WinUI 菜单。

• 添加/编辑课程时，“时间表”下拉框显示作息时间表中自定义的名称

&#x20; （例如“早读”“第1节”），而不是只显示“第几节”。

• 幸福倒计时结束时，会在 Windows 通知中心弹出“已抵达”通知。

• 设置窗口右下角增加 Copyright miProfessor 2026 水印。



三、主要功能

\------------

• 单周 / 双周课表分开维护，课程也可以设为“单双周通用”。

• 小组件仅显示今天尚未结束的课程；课程窗格随可用课程自动增减。

• 每个窗格显示距离上课的分钟数；距离不超过 1 分钟时显示“即将进行”。

• 设置中可自定义单次最多显示的课程数（1–8），并添加按时间段生效的

&#x20; “分时显示规则”，让显示数量在一天中自动变化。

• 可设置每天强制窗口置顶的时间段（支持跨夜时段，开始=结束表示全天）。

• 可以按开学日期自动计算当前是单周还是双周，也可以手动指定。

• 底部“幸福倒计时”可自定义目标时间与进度起点，右侧进度条显示进度。

&#x20; 倒计时结束后会显示 Windows 通知，并在通知中心保留。

• 在“作息时间”页可逐节编辑时间表名称与上下课时间，或从 CSV / TXT 导入。

• 小组件右上角的齿轮打开设置；设置窗口内的更改会自动保存并立即生效。

• 拖动小组件顶部空白区域可以移动位置，位置会自动记住。

• 支持设置开机自启动。



四、任务栏小图标

\----------------

程序启动后会出现在 Windows 通知区域（可能收纳在“^”隐藏图标里）。

在小图标上单击鼠标右键，会显示圆角菜单：

&#x20; · 隐藏/显示小组件

&#x20; · 小组件设置

&#x20; · 关闭小组件

左键单击小图标会重新显示小组件。



五、导入作息时间

\----------------

支持 .csv 和 .txt，每行一节课。推荐格式：

&#x20; 1,08:00,08:45

&#x20; 2,08:55,09:40

&#x20; 3,10:00,10:45



也支持：

&#x20; 早读,07:10,07:40

&#x20; 第1节,07:45,08:25



只有开始时间时，默认按 45 分钟计算。表头行会被自动忽略。

导入后可在“作息时间”页修改每节的“时间表名称”。



六、数据保存位置

\----------------

%LOCALAPPDATA%\\CourseWidget\\settings.json

所有课表、时间和倒计时设置都保存在这里。

从“通用”页可以直接打开数据文件夹或设置文件。

程序不会上传任何数据。



七、注意事项

\------------

• 如果移动了程序文件夹，请在“通用”页把“开机自启动”关闭再开启一次，

&#x20; 以更新启动路径。

• 若没有在通知中心看到倒计时通知，请确认 Windows 设置中允许

&#x20; “课程表小组件”发送通知，且未开启专注助手/请勿打扰。

• 若通知区域看不到图标，请点击任务栏右侧的“^”展开隐藏图标。

• 请勿删除程序文件夹中的 Assets、resources.pri 或各类依赖 DLL；

&#x20; 它们和 exe 一起构成完整程序。

• 推荐屏幕缩放 100%–250%，界面会在高 DPI 下自动缩放。
