# 课程表小组件-Class Schedule Widget

一个高效的小组件，提醒你一天的课程和日程



课程表小组件 v1.0.0（Windows 11 x64）

========================================



一、如何运行

\------------

1\. 请先把压缩包完整解压到一个固定文件夹（例如 D:\\Apps\\课程表小组件）。

&#x20;  不要在压缩包里直接双击运行，也不要放在系统临时目录中。

2\. 双击“课程表小组件.exe”即可启动。

&#x20;  本程序是自包含版本，无需另外安装 .NET 或 Windows App Runtime。

3\. 首次启动会同时打开小组件和设置窗口，请先在设置中填写课表、

&#x20;  作息时间和幸福倒计时。



二、主要功能

\------------

• 单周 / 双周课表分开维护，课程也可以设为“单双周通用”。

• 小组件仅显示今天尚未结束的课程；课程窗格随可用课程自动增减。

• 每个窗格显示距离上课的分钟数；距离不超过 1 分钟时显示“即将进行”。

• 设置中可自定义单次最多显示的课程数（1–8），并添加按时间段生效的

&#x20; “分时显示规则”，让显示数量在一天中自动变化。

• 可设置每天强制窗口置顶的时间段（支持跨夜时段）。

• 可以按开学日期自动计算当前是单周还是双周，也可以手动指定。

• 底部“幸福倒计时”可自定义目标时间与进度起点，右侧进度条显示进度。

• 在“作息时间”页可逐节编辑，或从 CSV / TXT 文件导入每节课的上下课时间。

&#x20; 也支持直接粘贴文本导入。

• 小组件右上角的齿轮打开设置；设置窗口内的更改会自动保存并立即生效。

• 拖动小组件顶部空白区域可以移动位置，位置会自动记住。

• 支持设置开机自启动。



三、任务栏小图标

\----------------

程序启动后会出现在 Windows 通知区域（可能收纳在“^”隐藏图标里）。

在小图标上单击鼠标右键，会显示以下菜单：

&#x20; · 关闭小组件

&#x20; · 小组件设置

&#x20; · 隐藏/显示小组件

左键单击小图标会重新显示小组件。



四、导入作息时间

\----------------

支持 .csv 和 .txt，每行一节课。推荐格式：

&#x20; 1,08:00,08:45

&#x20; 2,08:55,09:40

&#x20; 3,10:00,10:45



也支持：

&#x20; 第1节,08:00,08:45

&#x20; 08:00,08:45

&#x20; 08:00



只有开始时间时，默认按 45 分钟计算。表头行会被自动忽略。

设置窗口的“作息时间”页提供“选择文件导入”和“粘贴文本导入”。



五、数据保存位置

\----------------

%LOCALAPPDATA%\\CourseWidget\\settings.json

首次运行后，所有课表、时间和倒计时设置都保存在这里。

从“通用”页可以直接打开数据文件夹或设置文件。

程序不会上传任何数据。



六、注意事项

\------------

• 如果在开启开机自启动之后移动了程序文件夹，请到“通用”页把

&#x20; “开机自启动”关掉再打开一次，以更新启动路径。

• 若通知区域看不到图标，请点击任务栏右侧的“^”展开隐藏图标。

• 请勿删除程序文件夹中的 Assets、resources.pri 或各类依赖 DLL；

&#x20; 它们和 exe 一起构成完整程序。

• 推荐屏幕缩放 100%–250%，界面会在高 DPI 下自动缩放。
